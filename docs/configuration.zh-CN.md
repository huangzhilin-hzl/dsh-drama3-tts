## 服务分工

| 服务 | 作用 | 何时需要 |
| --- | --- | --- |
| Drama 3 或 Fish Audio | 根据口播稿合成声音；本地模式使用参考录音及逐字稿 | 生成新音频时 |
| 文本处理模型 | 精简口播稿、规划句级语气 | 精简或语气开关至少有一个开启时 |
| 语音识别模型 | 把实际音频转回文字，供程序检查中文句首 | 仅本地模式开启句首检查，且片段符合检查条件时 |

语音识别是可选能力。开启句首检查前，在设置中确认识别服务地址和该服务支持的模型 ID；关闭时无需部署识别服务。

本地合成调用 `${baseUrl}/v1/audio/speech`；文本和识别服务分别调用其配置地址后接 `/chat/completions`。因此合成地址通常不带 `/v1`，文本与识别地址通常带 `/v1`。后者只是常见部署方式，最终应以服务实际路由为准。

## 存储与保存

配置保存在 `$DSH_HOME/drama3-tts/config.json`，`DSH_HOME` 未设置时使用 `~/.dsh`。上传的参考录音在同级 `voices/`，音频缓存位于 `cache/`。读取存储配置时，缺失或类型不正确的字段使用代码默认值。提交设置时则按字段验证并合并补丁；未提供的字段保持原值，部分无效字段会被忽略或使请求报错，不会统一重置为默认值。

配置表中的**默认值**指代码初始值，已保存的设置优先。

### 声音与连接

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `provider` | `local` | `local` 或 `fish` |
| `baseUrl` | `http://127.0.0.1:18190` | 合成服务根地址；HTTP/HTTPS |
| `model` | `/home/models/drama-3` | 合成服务接受的模型 ID |
| `refAudioPath` | 空 | Host 可读的录音文件路径，本地模式必填 |
| `refText` | 空 | 参考录音的准确逐字稿，本地模式必填 |
| `speed` | `1` | `0.75`–`1.6`，保存时取两位小数 |
| `format` | `mp3` | `mp3` 或 `wav` |
| `apiKey` | 空 | 合成服务密钥；Fish 必填 |
| `voiceId` | `fbe02f8306fc4d3d915e9871722a39d5` | Fish 嘉岚 3.0 预设 ID；本地合成不使用它 |

在设置页切换到 Fish Audio 时，预设服务为 `https://api.fish.audio`、模型 `drama-3`。直接使用配置 API 切换提供方时，应一起设置正确的服务、模型和音色。

录音可上传 WAV、MP3、M4A、FLAC 或 OGG，文件上限 20 MiB；录音时长和编码还须满足上游服务要求。参考录音约束声音特点，逐字稿用于对齐，二者均应与实际音频一致。

插件把语速传给合成服务；浏览器播放速率固定为 `1`，避免再次加速。不要用修改参考逐字稿的方式控制语速。

### 口播内容

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `summaryEnabled` | `true` | 精简回复 |
| `summaryMaxChars` | `220` | 目标长度，范围 `80`–`800`；是软目标，不是截断长度 |
| `tagEnabled` | `true` | 句级语气编排；关闭后不自动加入导演标签 |
| `tagMax` | `3` | 全文语气控制预算，范围 `1`–`6` |
| `tagMode` | `strip` | 清洗输入时剥离原有标签；`keep` 保留可接受的原有标签 |
| `tagBaseUrl` | `http://127.0.0.1:18188/v1` | 文本处理服务地址 |
| `tagModel` | `dsv41-flash` | 文本处理模型 ID，可更换 |
| `tagApiKey` | 空 | 文本处理服务密钥 |
| `pronunciationEnabled` | `true` | 应用内置术语读法和自定义词典 |
| `pronunciationLexicon` | 空 | 每行 `术语 = 读法` |
| `wholeReplyEnabled` | `true` | 短回复尽量整段合成 |
| `maxChars` | `180` | 分段目标，范围 `60`–`600`；实际边界还受标点和载荷限制 |

文本处理密钥的回退顺序是 `tagApiKey`、`MOLOU_DEV_API_KEY`、`OPENAI_API_KEY`。配置 GET 响应只提供 `hasApiKey`、`hasTagApiKey` 标志，不返回密钥。选择远程服务会把相应的回复、上下文或音频发到所配置的地址。

提示词要求摘要保留关键结论、证据和限制。程序校验结构、摘要是否变长、是否引入新数值及改变带数字的技术标识；它不能证明否定关系、条件或语义完整性得到保留。`6.5×` 与 `6.5 倍` 可等价转换，`6.5×2` 仍按乘法处理。首次内容校验失败会要求模型修正一次，仍失败才回退清洗后的原回复。结构解析失败或服务不可用则直接回退。

句级计划须与正文逐句对齐，不改写正文；无效计划采用规则断句。编译器使用统一讲述提示，以及预算内的强调、短停顿或收尾提示。停顿标签不承诺固定毫秒数。可保留的成对标签包括 `emphasis`、`whisper`、`soft`、`fast`、`slow`、`stress`、`forceful`。

术语词典示例：

```text
KV cache = K V 缓存
```

自定义词典优先于内置规则，最多 100 条，仅接受普通文本读法；不要填控制标签或音素标记。内置规则对部分英语词使用音素控制，对缩写使用字母拆读；未命中的词不会凭空猜读法。英语词条参考 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)。品牌和缩写读法仍需试听确认。

正文可读长度与 `spokenUnits` 均不超过 320，且实际合成文本不超过 1200 字符时，整段合成生效。音素标记可能让实际载荷提前达到上限。超过限制时自然分段；各段独立合成，不保证音色与气声完全一致。生成预算依据正文及音素长度取 `1024`–`2048` 个输出 token，不是音频时长保证。

### 可选句首检查

| 字段 | 设置方式 |
| --- | --- |
| `speechCheckEnabled` | 默认 `false`；按需开启本地模式的中文句首检查 |
| `speechCheckBaseUrl` | 填写识别服务的 API 基础地址，请求会在其后追加 `/chat/completions` |
| `speechCheckModel` | 填写所配置识别服务支持的模型 ID |

启用后，符合条件的片段通过以下流程：

1. Drama 3 生成音频。
2. 识别服务转写实际音频；请求不提供预期台词，避免引导模型补全。
3. 程序比较中文句首，疑似漏读时换一次采样重新生成。
4. 最多合成两次；仍不匹配则报错，不播放、不缓存该候选。识别服务不可用也会阻止这些待检查片段播放。

仅为至少 6 个汉字的纯中文首句建立锚点；含英文、数字或音素控制的首句以及短问候会跳过。首句超过 40 个汉字时只核对前 24 个字，允许少量识别误差。识别接口需兼容 `audio_url` 数据 URL 输入、`modalities: ["text"]` 及 `choices[0].message.content` 纯文本响应；当前请求不附带合成或文本服务的密钥。

这项检查不核验全文、英文发音或后半段重复音节。识别也会漏字或产生重复文本，因此识别结果只是诊断证据之一。关闭后，正常朗读不依赖识别服务。
